# MentorTrack - Next.js Fullstack

Mentoring folyamatokat kezelő alkalmazás (Mentoráltak óraszámainak követése, session foglalások, statisztikák).

## Technológiai Stack
- **Frontend/Backend:** Next.js 15 (App Router)
- **Statisztikák:** Recharts
- **Stílus:** CSS + Tailwind + Lucide Icons
- **Adatbázis & Auth:** Supabase

## Lokális futtatás

1. Telepítsd a függőségeket: `npm install`
2. Másold át a `.env.local` fájlt és töltsd ki a Supabase adataival.
3. Indítsd el a fejlesztői szervert: `npm run dev`

Az alkalmazás mostantól tisztán Next.js alapú, nincs szükség külön backend futtatására.
